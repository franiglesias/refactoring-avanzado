# Bloaters

Los **Bloaters** son code smells en los que se complica el cambio en el código porque las unidades son demasiado grandes o por obligarnos a introducir mucho código auxiliar.

## Ejercicios

| Code Smell | Descripción | Dificultad |
|------------|-------------|------------|
| [Data Clump](data-clump.md) | Grupo de datos que siempre viajan juntos | ⭐⭐ |
| [Large Class](large-class.md) | Clase con demasiadas responsabilidades | ⭐⭐⭐ |
| [Long Method](long-method.md) | Método excesivamente largo | ⭐⭐⭐⭐ |
| [Long Parameter List](long-parameter-list.md) | Método con muchos parámetros | ⭐⭐ |
| [Primitive Obsession](primitive-obsession.md) | Uso excesivo de tipos primitivos | ⭐⭐ |

## Leyenda de Dificultad

- ⭐ **Fácil**: Refactoring directo, cambios localizados
- ⭐⭐ **Moderado**: Requiere planificación, múltiples pasos
- ⭐⭐⭐ **Avanzado**: Cambios estructurales, impacto en múltiples componentes
- ⭐⭐⭐⭐ **Experto**: Refactoring complejo, requiere técnicas avanzadas

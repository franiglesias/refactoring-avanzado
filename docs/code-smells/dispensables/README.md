# Dispensables

Los **Dispensables** son code smells debidos a código innecesario, que introduce ruido dificultando la inteligibilidad del código.

## Ejercicios

| Code Smell | Descripción | Dificultad |
|------------|-------------|------------|
| [Comments](comments.md) | Comentarios que compensan código poco claro | ⭐ |
| [Data Class](data-class.md) | Clase sin comportamiento | ⭐⭐ |
| [Dead Code](dead-code.md) | Código que nunca se ejecuta | ⭐ |
| [Duplicated Code](duplicated-code.md) | Código repetido | ⭐⭐ |
| [Lazy Class](lazy-class.md) | Clase que hace muy poco | ⭐ |

## Leyenda de Dificultad

- ⭐ **Fácil**: Refactoring directo, cambios localizados
- ⭐⭐ **Moderado**: Requiere planificación, múltiples pasos

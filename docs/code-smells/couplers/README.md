# Couplers

Los **Couplers** son code smells en los que cambios en una unidad fuerzan cambios en otra que tiene un acoplamiento muy fuerte.

## Ejercicios

| Code Smell | Descripción | Dificultad |
|------------|-------------|------------|
| [Feature Envy](feature-envy.md) | Método que usa más datos de otra clase | ⭐⭐ |
| [Inappropriate Intimacy](inappropriate-intimacy.md) | Clases demasiado acopladas | ⭐⭐⭐ |
| [Message Chains](message-chains.md) | Cadenas largas de llamadas | ⭐⭐ |
| [Middleman](middleman.md) | Clase que solo delega | ⭐ |

## Leyenda de Dificultad

- ⭐ **Fácil**: Refactoring directo, cambios localizados
- ⭐⭐ **Moderado**: Requiere planificación, múltiples pasos
- ⭐⭐⭐ **Avanzado**: Cambios estructurales, impacto en múltiples componentes

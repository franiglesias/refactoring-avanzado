# OOP Abusers

Los **OOP Abusers** son code smells debido a la aplicación inadecuada de la orientación a objetos.

## Ejercicios

| Code Smell | Descripción | Dificultad |
|------------|-------------|------------|
| [Alternative Classes with Different Interfaces](alternative-classes-different-interfaces.md) | Clases similares con interfaces diferentes | ⭐⭐ |
| [Refused Bequest](refused-bequest.md) | Subclase que no usa la herencia recibida | ⭐⭐⭐ |
| [Switch Statements](switch-statements.md) | Switch sobre tipos en lugar de polimorfismo | ⭐⭐ |
| [Temporal Instance Variables](temporal-instance-variables.md) | Variables de instancia válidas solo en ciertas fases | ⭐⭐ |

## Leyenda de Dificultad

- ⭐⭐ **Moderado**: Requiere planificación, múltiples pasos
- ⭐⭐⭐ **Avanzado**: Cambios estructurales, impacto en múltiples componentes
